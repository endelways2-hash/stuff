## 1. Замена: условное равенство через Element с повторным target

В `_v3_build_model`, внутри `if fresh`, сейчас создаётся:

```python
model.add(before == b).only_enforce_if(hit)
```

Заменяем **только эту строку** на:

```python
_v2_add_mux(model, hit, before, b, before)
```

Это записывает:

\[
\texttt{before}=[\texttt{before},\texttt{b}][\texttt{hit}].
\]

Семантика `Element` — равенство target элементу массива с выбранным индексом. Поэтому:

- `hit = 0`: получается `before = before`, никаких дополнительных требований;
- `hit = 1`: получается `before = b`.

Следовательно, при булевом домене `hit`:

\[
\boxed{
(\texttt{hit}=1\Rightarrow\texttt{before}=\texttt b)
\;\Longleftrightarrow\;
\operatorname{Element}(\texttt{hit},[\texttt{before},\texttt b],\texttt{before})
}
\]

Это **эквивалентность на тех же переменных**, а не ослабление модели и не только сохранение SAT/UNSAT. ([raw.githubusercontent.com](https://raw.githubusercontent.com/google/or-tools/v9.15/ortools/sat/python/cp_model.py))

**Важно использовать именно существующий `_v2_add_mux`.** Он записывает компактные legacy-поля `index/target/vars`, без коэффициентов линейных выражений. Просто вызвать современный `add_element` без преобразования protobuf недостаточно для гарантии по числу коэффициентов. Legacy-поля присутствуют в схеме OR-Tools 9.15, а нужный helper уже есть в вашем файле. ([raw.githubusercontent.com](https://raw.githubusercontent.com/google/or-tools/v9.15/ortools/sat/cp_model.proto))

### Изменение одного блока

| Метрика | Условное равенство | Новый Element |
|---|---:|---:|
| Дополнительные переменные | 0 | 0 |
| Ограничения | 1 | 1 |
| Арность, включая enforcement | 3 | 3 |
| Записи коэффициентов | 2 | **0** |
| Максимальный модуль коэффициента блока | 1 | **0** |
| Явные endpoints линейного домена | 2 | **0** |

Множество используемых индексов одинаково: `{hit, before, b}`. Повторное упоминание `before` не увеличивает арность: ваш счётчик использует множество индексов.

Остальные `Element`, `AllDifferent`, modulo, окна, переменные и их домены **не меняются**. Дополнительные предположения о соседних дублях, различных префиксах и использовании всех карт для этой замены не требуются — она верна и без них.

## 3. Доказательство на Lean

Файл `DeckSelfElement.lean`. Используется Lean 4 со стандартной библиотекой, без Mathlib.

Доказано:

1. точное локальное равенство семантик;
2. эквивалентность всей модели в **произвольном неизменённом контексте**;
3. сохранение любых наблюдаемых результатов, включая исходную колоду и выходные позиции;
4. неувеличение всех семи метрик;
5. требуемые численные неравенства для профиля CSV.

`Rest` ниже означает все неизменённые ограничения и домены. Поскольку теорема верна для **любого** `Rest`, это не предположение о корректности конкретного ограничения.

```lean
import Std
import Lean.Elab.Tactic.Omega

namespace DeckSelfElement

abbrev Assignment := Nat → Int

def BoolDomain (h : Int) : Prop :=
  h = 0 ∨ h = 1

def GuardEq (h x y : Int) : Prop :=
  h = 1 → x = y

-- Точная семантика Element с массивом длины 2.
def Element2 (h x0 x1 target : Int) : Prop :=
  (h = 0 ∧ target = x0) ∨
  (h = 1 ∧ target = x1)

theorem guard_element_iff
    (h x y : Int) (hb : BoolDomain h) :
    GuardEq h x y ↔ Element2 h x y x := by
  cases hb with
  | inl h0 =>
      subst h
      simp [GuardEq, Element2]
  | inr h1 =>
      subst h
      simp [GuardEq, Element2]

structure Guard where
  hit    : Nat
  before : Nat
  dest   : Nat

def OldLocal (g : Guard) (σ : Assignment) : Prop :=
  BoolDomain (σ g.hit) ∧
  GuardEq (σ g.hit) (σ g.before) (σ g.dest)

def NewLocal (g : Guard) (σ : Assignment) : Prop :=
  BoolDomain (σ g.hit) ∧
  Element2 (σ g.hit) (σ g.before) (σ g.dest) (σ g.before)

theorem local_equiv (g : Guard) (σ : Assignment) :
    OldLocal g σ ↔ NewLocal g σ := by
  constructor
  · intro h
    exact ⟨h.1,
      (guard_element_iff
        (σ g.hit) (σ g.before) (σ g.dest) h.1).mp h.2⟩
  · intro h
    exact ⟨h.1,
      (guard_element_iff
        (σ g.hit) (σ g.before) (σ g.dest) h.1).mpr h.2⟩

-- Проверяем также, что множество используемых переменных не меняется.
def OldUses (g : Guard) (v : Nat) : Prop :=
  v = g.hit ∨ v = g.before ∨ v = g.dest

def NewUses (g : Guard) (v : Nat) : Prop :=
  v = g.hit ∨ (v = g.before ∨ v = g.before) ∨ v = g.dest

theorem same_variables (g : Guard) (v : Nat) :
    OldUses g v ↔ NewUses g v := by
  simp [OldUses, NewUses]

def OldModel
    (Rest : Assignment → Prop)
    (guards : List Guard)
    (σ : Assignment) : Prop :=
  Rest σ ∧ ∀ g ∈ guards, OldLocal g σ

def NewModel
    (Rest : Assignment → Prop)
    (guards : List Guard)
    (σ : Assignment) : Prop :=
  Rest σ ∧ ∀ g ∈ guards, NewLocal g σ

theorem models_equivalent
    (Rest : Assignment → Prop)
    (guards : List Guard)
    (σ : Assignment) :
    OldModel Rest guards σ ↔ NewModel Rest guards σ := by
  constructor
  · intro h
    refine ⟨h.1, ?_⟩
    intro g hg
    exact (local_equiv g σ).mp (h.2 g hg)
  · intro h
    refine ⟨h.1, ?_⟩
    intro g hg
    exact (local_equiv g σ).mpr (h.2 g hg)

-- observe может извлекать исходную колоду, выходные позиции
-- или вообще любой результат из присваивания.
theorem projected_equiv
    {α : Type}
    (Rest : Assignment → Prop)
    (guards : List Guard)
    (observe : Assignment → α)
    (value : α) :
    (∃ σ, OldModel Rest guards σ ∧ observe σ = value) ↔
    (∃ σ, NewModel Rest guards σ ∧ observe σ = value) := by
  constructor
  · intro h
    cases h with
    | intro σ hs =>
        exact ⟨σ,
          (models_equivalent Rest guards σ).mp hs.1,
          hs.2⟩
  · intro h
    cases h with
    | intro σ hs =>
        exact ⟨σ,
          (models_equivalent Rest guards σ).mpr hs.1,
          hs.2⟩

structure Profile where
  variables          : Nat
  constraints        : Nat
  totalArity         : Nat
  maxArity           : Nat
  coefficientEntries : Nat
  maxCoefficient     : Nat
  rhsEndpoints       : Nat
  deriving DecidableEq, Repr

-- r содержит профиль неизменённых ограничений.
-- Все объявления переменных уже учтены в r.variables.
-- В данном генераторе три индекса каждого guard различны.
def beforeProfile (r : Profile) (L : Nat) : Profile :=
  { variables          := r.variables
    constraints        := r.constraints + L
    totalArity         := r.totalArity + 3 * L
    maxArity           := max r.maxArity (if L = 0 then 0 else 3)
    coefficientEntries := r.coefficientEntries + 2 * L
    maxCoefficient     := max r.maxCoefficient (if L = 0 then 0 else 1)
    rhsEndpoints       := r.rhsEndpoints + 2 * L }

def afterProfile (r : Profile) (L : Nat) : Profile :=
  { variables          := r.variables
    constraints        := r.constraints + L
    totalArity         := r.totalArity + 3 * L
    maxArity           := max r.maxArity (if L = 0 then 0 else 3)
    coefficientEntries := r.coefficientEntries
    maxCoefficient     := r.maxCoefficient
    rhsEndpoints       := r.rhsEndpoints }

def NoIncrease (new old : Profile) : Prop :=
  new.variables          ≤ old.variables ∧
  new.constraints        ≤ old.constraints ∧
  new.totalArity         ≤ old.totalArity ∧
  new.maxArity           ≤ old.maxArity ∧
  new.coefficientEntries ≤ old.coefficientEntries ∧
  new.maxCoefficient     ≤ old.maxCoefficient ∧
  new.rhsEndpoints       ≤ old.rhsEndpoints

theorem never_increases (r : Profile) (L : Nat) :
    NoIncrease (afterProfile r L) (beforeProfile r L) := by
  dsimp [NoIncrease, beforeProfile, afterProfile]
  refine ⟨Nat.le_refl _, Nat.le_refl _, Nat.le_refl _,
    Nat.le_refl _, ?_, ?_, ?_⟩
  · omega
  · exact Nat.le_max_left _ _
  · omega

theorem coefficients_at_least_halved
    (r : Profile) (L : Nat)
    (h : r.coefficientEntries ≤ 2 * L) :
    2 * (afterProfile r L).coefficientEntries ≤
      (beforeProfile r L).coefficientEntries := by
  dsimp [afterProfile, beforeProfile]
  omega

theorem endpoints_at_least_halved
    (r : Profile) (L : Nat)
    (h : r.rhsEndpoints = 0) :
    2 * (afterProfile r L).rhsEndpoints ≤
      (beforeProfile r L).rhsEndpoints := by
  dsimp [afterProfile, beforeProfile]
  omega

-- Профиль неизменённой части для полного динамического CSV.
def csvRest : Profile :=
  { variables          := 83 + 39287 + 39287 + 1027
    constraints        := 39287 + 1027 + 13095 + 861
    totalArity         := 4 * 39287 + 2 * 1027 + 38260 + 13095 + 3403
    maxArity           := 4
    coefficientEntries := 2 * 1027 + 38260 + 13095 + 3403
    maxCoefficient     := 1
    rhsEndpoints       := 0 }

def csvBefore : Profile := beforeProfile csvRest 39287
def csvAfter  : Profile := afterProfile csvRest 39287

example :
    csvBefore =
      ⟨79684, 93557, 331821, 4, 135386, 1, 78574⟩ := by
  decide

example :
    csvAfter =
      ⟨79684, 93557, 331821, 4, 56812, 1, 0⟩ := by
  decide

example : NoIncrease csvAfter csvBefore :=
  never_increases csvRest 39287

example :
    2 * csvAfter.coefficientEntries ≤
      csvBefore.coefficientEntries := by
  decide

example :
    2 * csvAfter.rhsEndpoints ≤ csvBefore.rhsEndpoints := by
  decide

-- Уменьшение endpoints здесь не является случаем 0 → 0.

  decide
```

## 4. Проверка соответствия реальному protobuf

Сохраните исходный v3 без изменений. Следующий файл `check_self_element_v4.py` создаёт изменённый модуль **только в памяти**. Сервер не запускается, рабочая папка и очередь не изменяются.

Он проверяет:

- одинаковые переменные, домены и выходные индексы;
- что каждое изменённое ограничение соответствует доказанной замене;
- точное совпадение остальных ограничений;
- неувеличение всех метрик;
- совпадение полных результатов перебора малых моделей.

```python
from pathlib import Path
import sys
import types

path = Path(sys.argv[1]).resolve()
csv_path = (
    Path(sys.argv[2]).resolve()
    if len(sys.argv) > 2
    else path.with_name("data.csv")
)
source = path.read_text(encoding="utf-8-sig")

needle = "model.add(before == b).only_enforce_if(hit)"
replacement = "_v2_add_mux(model, hit, before, b, before)"
assert source.count(needle) == 1, "Исходник отличается от ожидаемого v3"


def load(text, name):
    module = types.ModuleType(name)
    module.__file__ = str(path)
    sys.modules[name] = module
    exec(compile(text, str(path), "exec"), module.__dict__)
    return module


old = load(source, "deck_original_check")
new = load(source.replace(needle, replacement, 1), "deck_changed_check")


def compare(label, messages, n, d, s, k):
    a, ai, ao = old.build_model(messages, n, d, s, k, lambda: None)
    b, bi, bo = new.build_model(messages, n, d, s, k, lambda: None)

    assert not a.validate(), a.validate()
    assert not b.validate(), b.validate()

    pa = old._reduced_proto(a)
    pb = new._reduced_proto(b)

    assert ai == bi and ao == bo
    assert pa.variables == pb.variables
    assert len(pa.constraints) == len(pb.constraints)

    for ca, cb in zip(pa.constraints, pb.constraints):
        if not ca.HasField("linear"):
            assert ca == cb
            continue

        assert len(ca.enforcement_literal) == 1
        hit = ca.enforcement_literal[0]
        assert hit >= 0
        assert list(pa.variables[hit].domain) == [0, 1]
        assert list(ca.linear.domain) == [0, 0]
        assert len(ca.linear.vars) == 2
        assert sorted(ca.linear.coeffs) == [-1, 1]

        assert cb.HasField("element")
        assert not cb.enforcement_literal
        el = cb.element
        assert el.index == hit
        assert len(el.vars) == 2
        assert el.target == el.vars[0]
        assert set(el.vars) == set(ca.linear.vars)
        assert not el.HasField("linear_index")
        assert not el.HasField("linear_target")
        assert not el.exprs

    sa = old._v2_stats(pa)
    sb = new._v2_stats(pb)

    for metric in sa:
        assert sb[metric] <= sa[metric], (metric, sa, sb)

    assert sb["rhs_endpoints"] == 0
    assert (
        sb["coefficient_entries"]
        == sa["coefficient_entries"] - sa["rhs_endpoints"]
    )

    print(label, "before:", sa)
    print(label, "after: ", sb)
    return sa, sb


small_cases = [
    (3, 1, 0, 1, [[0, 1, 0, 1]]),
    (3, 1, 0, 1, [[0, 1, 2]]),
    (5, 2, 0, 2, [[0, 1, 0, 2], [0, 2, 1]]),
    (4, 0, 1, 1, [[0, 1, 2, 3]]),
]

for n, d, s, k, messages in small_cases:
    compare("small", messages, n, d, s, k)
    solutions_a, _ = old._reduced_enumerate(
        old.build_model, messages, n, d, s, k
    )
    solutions_b, _ = new._reduced_enumerate(
        new.build_model, messages, n, d, s, k
    )
    assert solutions_a == solutions_b

compare(
    "synthetic",
    [[0, 1] * 600 + [2, 3, 4]],
    83, 1, 0, 1,
)

_, n, messages, _ = old.read_data_csv(csv_path)
assert old._v3_counts(messages) == (39287, 39287, 38260, 13095)

sa, sb = compare("CSV", messages, n, 1, 0, 1)
assert 2 * sb["coefficient_entries"] <= sa["coefficient_entries"]
assert sa["rhs_endpoints"] > 0

print("SELF-ELEMENT CHECK OK")
```
